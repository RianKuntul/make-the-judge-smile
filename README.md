Entry for the make.fun **Make the Judge Smile** — one original line about a small good thing that happened today, warm enough to make a reader smile. The program writes the line to `entry.txt`; a hard guard refuses to run if the line ever exceeds 200 characters.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> The warung lady tucked one last krupuk into my nasi uduk this morning and whispered, 'for the road' — I crunched it at the red light, still warm, and grinned like I'd won something.
